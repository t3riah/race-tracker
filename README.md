# Race Tracker

A lean, plain-language introduction to the tennis season: ATP and WTA race to the year-end finals, with points, next win totals, max totals for the current event, and gap to the effective cut.

Dated snapshot: Oct 26, 2026. ATP data from the official ATP Live Race to Turin page. WTA data from the official WTA race table, cross-checked against live-tennis.eu. WTA next and max totals are marked Pending in this version, not guessed.

Live site: https://t3riah.github.io/race-tracker/
